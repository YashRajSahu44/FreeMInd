# FreeMind Personnel Wellness Prototype

## Scope
- Build a polished, responsive personnel overview at `/` and detailed analytics at `/analytics`.
- Add working app navigation for Dashboard, My Analytics, Wellness, Alerts, and Profile, with lightweight supporting screens for the latter three.
- Use the uploaded FreeMind logo through the project asset flow and label all displayed information as demo/synthetic.

## Experience
- Create a clean white and soft-mint government wellness interface with charcoal text, restrained amber warnings, rounded cards, subtle borders, and clear hierarchy.
- Provide desktop and tablet navigation, personalized officer context, notifications, gauges, metric cards, timelines, privacy messaging, and non-medical early-warning language.
- Make the detailed page chart-led, including stress, workload, sleep, deployment, leave/recovery, and voluntary check-in analytics with hover tooltips and selectable date ranges.

## Technical approach
- Use TanStack Start’s React routing and Tailwind CSS design tokens.
- Add Recharts and Lucide icons, with reusable shell, card, gauge, chart, and metric components.
- Keep all data local and synthetic; no backend, external APIs, authentication screen, or persistent personal data.
- Add unique metadata for every content route and verify the live preview at laptop and tablet sizes.
